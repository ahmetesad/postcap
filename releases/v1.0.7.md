# Postcap v1.0.7

Now you can preview edits before exporting (long overdue)!

## What's new

- Preview export speed (with pitch-preserving playback)
- Preview selected, muted, and volume-adjusted audio tracks
- Toggle edit previews from the playback controls

## Fixes

- Trim end is now respected when exporting at a different speed
- Fixed a sidebar crash caused by playback updates
